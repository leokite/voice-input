# VoiceInput 使い方ガイド

VoiceInput は、キーを押して話すだけで、今使っているアプリのカーソル位置に文字を入れる Mac のメニューバーアプリです。日本語、英語、日本語と英語が混ざった話し方に対応しています。

インストールと最初の設定は [セットアップ手順](setup.md) を見てください。このガイドは、入れ終わった後の使い方です。

## 1. 基本の使い方

文字を入れたいアプリで、入力欄にカーソルを置いてから、**右 Option キー**を使います。録音のしかたは 2 通りあります。

| やり方 | 操作 |
|---|---|
| 短く押して開始と停止 | 右 Option を短く押して離す → 話す → もう一度、短く押して離す |
| 押し続けて録音 | 右 Option を押し続けたまま話す → 離す |

- 0.3 秒より短く押して離すと「短く押す」、0.3 秒以上押し続けると「押し続ける」になります。この境目は設定で変えられます。
- 録音中は、画面の下部中央に小さな表示が出ます。録音中は音の大きさに合わせて動き、文字にしている間は「変換中」になります。表示をクリックしても、入力中のアプリからカーソルは外れません。
- 話し終えると、整えた文章がまとめてカーソル位置に入ります。
- 押し続けている間に別のキーを押すと、普通のキー操作（Option+← など）とみなして、録音を取り消します。このとき文字は入りません。
- 短く押して始めた録音を止め忘れても、無音が 60 秒続くと自動で止まります（設定で変えられます）。

### 自動で整えること

- **フィラーを消す**: 「えー」「えっと」「あのー」「um」「uh」などを消します。消す語は設定で変えられます。
- **用語集の置き換え**: 用語集に登録した「置き換え」を自動で適用します（[3 章](#3-用語集で認識を良くする)）。
- 句読点は、文字起こしサービスが付けたものをそのまま使います。

### 文字が入らないとき

- **別のアプリに切り替えた**: 録音を始めたときに前面にあったアプリから別のアプリに移ると、文字は入れずに履歴にだけ残します。表示に「履歴に保存しました」と出ます。履歴から、コピーして貼り付けられます。
- **パスワード入力中**: 文字を送り込めないので、何も入れずに表示で知らせます。

JIS 配列の MacBook には右 Option がありません。その場合は、設定で別のキー（右 Command など）に変えてください。

## 2. メニューバーのメニュー

メニューバーのマイクのアイコンを押すと、次の項目が出ます。Dock にはアイコンは出ません。

| 項目 | できること |
|---|---|
| アクセシビリティの許可が必要です | キーの監視ができていないときだけ出ます。押すと権限の画面が開きます。 |
| 録音の開始と停止 | キーを使わずに、メニューから録音を始めたり止めたりします。 |
| 履歴 | 過去の文字起こしを見たり、コピーしたり、用語集に登録したりします。 |
| 用語集 | 用語と置き換えを見たり、足したり、直したり、消したりします。 |
| 設定 | キーや文字起こしの方法などを変えます。 |
| 権限 | マイクとアクセシビリティの許可の状態を見ます。 |
| 終了 | VoiceInput を終了します。 |

## 3. 用語集で認識を良くする

専門用語や固有名詞は、そのままだと別の語に聞き間違えられることがあります。用語集に登録すると、使うほど精度が上がります。用語集には 2 種類の登録があります。

### 用語（認識のヒント）

「Kubernetes」「useEffect」のような語を登録します。文字起こしのときに、この語が出てくるかもしれないとエンジンに毎回伝えます。聞き間違いを減らす効果があります。

### 置き換え

「ぎっとはぶ → GitHub」のように、文字起こしの結果の中の特定の文字列を、別の表記に自動で直します。

- 置き換え先の語は、用語（ヒント）にも自動で加わります。
- 文字列をそのまま書き換えます。そのため、短い置き換え元（例:「リア」）は、別の語（「リアル」）の一部まで書き換えてしまいます。短い語や、普通の言葉は置き換えにしないでください。
- 同じ置き換え元を登録し直すと、置き換え先が上書きされます。
- 置き換え元が長いものから順に適用します。

### 用語集の画面

メニューの「用語集」を開くと、用語と置き換えの一覧があります。

- 「新しい用語」に入力して「追加」を押すと、用語を足せます。一覧の用語は直接書き換えたり、ごみ箱のボタンで消したりできます。
- 「置き換え」の欄に、置き換え元と置き換え先を入れて「追加」を押すと、置き換えを足せます。
- 一覧には、最後に使った時期も出ます。使われていない古い用語は、整理してください。

### 用語が多すぎるとき

用語が増えすぎると、認識のヒントとして送れる量の上限を超えます。上限を超えると、最近使った用語が優先され、古い用語は送られません。そのときは、設定の「用語集」に警告が出ます。古い用語を整理してください。ローカル（オフライン）モードでは、さらに上限が小さくなります。

## 4. 直した単語をキーひとつで登録する

音声入力が単語を聞き間違えたとき、手で直したその場で、直した単語を用語集に登録できます。

### 手順

1. 話して、文字を入れます。例:「どうかコンテナを再起動します」と入ってしまった。
2. 手で直します。例:「どうか」を「Docker」に打ち直す。
3. 直した部分を選びます。単語だけ（「Docker」）でも、前後を含む範囲（「Dockerコンテナを再起動」）でもかまいません。
4. **⌃⌥D**（Control + Option + D）を押します。
5. 画面の下部中央に「Docker を登録しました」と 3 秒間表示されます。

表示が出ている 3 秒の間に、もう一度 ⌃⌥D を押すと、その登録を取り消せます。3 秒を過ぎたものは、用語集の画面から消してください。

### 何が登録されるか

- 直した後の語（Docker）は、必ず用語（ヒント）に登録されます。
- 直す前の語が普通の言葉でなければ、置き換え（例:「キューバーニーツ → Kubernetes」）も登録されます。
- 直す前の語が「どうか」のような普通の言葉のときは、置き換えは登録されません。本当に「どうか」と言いたいときに、Docker に変わってしまうのを防ぐためです。ヒントだけが登録されます。
- 普通の言葉かどうかは、Mac の中の AI（Apple Intelligence）で判断します。Apple Intelligence が使えない Mac では判断できないので、置き換えは登録されず、ヒントだけが登録されます。使えない理由は、設定の「用語集」に出ます。
- 置き換え元が 2 文字以下のときも、ヒントだけです。

### 使えるときと使えないとき

- 直前の 10 分以内の音声入力（新しい順に最大 5 件）と照らし合わせます。音声入力していない文字は登録できません。
- 選べる文字は 200 文字までです。
- 録音中や変換中は使えません。「処理中です」と出ます。
- パスワード入力中は使えません。
- 何も選ばずに押すと、「文字を選んでからキーを押してください」と出ます。
- ひらがなだけの語（語尾の直しなど）や、1 文字だけの語は登録されません。「登録できる直しが見つかりませんでした」と出ます。

### キーを変える

設定の「用語集」の「直した単語を登録するキー」で変えられます。⌃（Control）か ⌥（Option）を含む組み合わせにしてください。⇧ や ⌘ だけの組み合わせは、普段の入力を邪魔するので選べません。

### 外部 AI（OpenAI）で置き換え元を探す（任意）

単語だけを選んだときなどは、直す前の語が分からないことがあります。そのときは、設定の「外部AI（OpenAI）で置き換え元を探す」をオンにすると、OpenAI に聞いて探せます。

- 初期値はオフです。オンにするには、OpenAI の API キーとモデル名が必要です。
- オンにすると、直前の音声入力の文と直した語を、OpenAI に送ります。
- キーがない、時間切れ（5 秒）、つながらないときは、ヒントだけを登録して、その旨を表示に添えます。
- ローカル（オフライン）モードでは使えません。

## 5. 設定の項目

メニューの「設定」で変えられます。

| 項目 | 内容 |
|---|---|
| 文字起こし | 「Soniox」（クラウド）か「ローカル（オフライン）」。録音中や処理中は切り替えられません。 |
| ローカルのモデル | ローカルのモデルの状態、ダウンロード、削除。 |
| API キー | Soniox の API キー。ローカルでは使いません。 |
| キー: 短く押して開始と停止 | 初期値は右 Option。「押して設定」を押してから、使いたいキーを押します。 |
| キー: 押し続けて録音 | 初期値は右 Option。 |
| 短押しと長押しの境目 | 0.15〜1.0 秒。初期値は 0.3 秒。 |
| 文字の入れ方 | 「話し終えてからまとめて」（初期値）か「文の区切りごと」。ローカルでは「まとめて」だけです。 |
| 言語のヒント | 話す言語。初期値は ja, en。 |
| 無音で自動停止 | 10〜600 秒。初期値は 60 秒。 |
| 用語集 | 登録キーと、OpenAI の設定。 |
| ログイン時に起動 | オンにすると、Mac にログインしたときに自動で起動します。 |
| フィラー | 消す語の一覧。追加、削除、「初期値に戻す」ができます。 |

録音に使えるキーは、修飾キー（右 Option、右 Command、右 Control、Fn など）と F13〜F19 だけです。普通の文字キーを録音キーにすると、どのアプリでも打てなくなるためです。キーを選んでいる途中で Esc を押すと、取り消せます。

「文字の入れ方」を「文の区切りごと」にすると、文の区切りが来るたびに、確定した部分を順に入れていきます（話しながら入ります）。

## 6. ローカル（オフライン）モード

音声も文字も Mac の外に出さずに、文字起こしします。ネットワークがなくても動きます。Soniox の API キーも要りません。

### 使い始める

1. メニューの「設定」を開き、「文字起こし」を「ローカル（オフライン）」にします。
2. 「ローカルのモデル」の「ダウンロード（約 1.5GB）」を押します。通信するのは、このときだけです。
3. 状態が「準備中」から「使える」に変われば終わりです。「準備中」は、最初の 1 回だけ数分かかります。

### ローカルでの違い

- 文字は、話し終えてからまとめて入ります（区切りごとには入りません）。
- OpenAI を使う項目は使えません。
- 用語集の用語は、認識のヒントとして使われます。ただし、長さの上限が小さくなります。
- 起動直後や、アプリ・macOS の更新の後は、モデルの読み込みに時間がかかります（更新の後は 1〜2 分）。状態が「使える（読み込み中）」のあいだは、録音できません。「使える」になってから話してください。
- Soniox に戻すときは、「文字起こし」を「Soniox」にします。設定は残っています。
- 履歴と用語集は、Soniox と同じ形で保存されます。切り替えても、そのまま使えます。

## 7. 履歴

メニューの「履歴」で、過去の文字起こし（最新の約 200 件）を見られます。

- **コピー**: その文を、クリップボードにコピーします。
- **未挿入**: 入力先に入らず、履歴にだけ残ったものです。コピーして貼り付けられます。
- **用語集に登録**: 文の中の聞き間違えた部分を選んでから押すと、置き換え元に入った状態で、登録の画面が開きます。置き換え先に正しい表記を入れて「登録」を押すと、置き換えと用語が登録されます。何も選ばずに押すと、文全体が置き換え元になります。

## 8. プライバシー

| モード | 音声 | 文字 |
|---|---|---|
| Soniox（初期値） | 録音した音声を Soniox（米国のクラウドサービス）に送って文字起こしする | 用語集の用語を、認識のヒントとして Soniox に送る |
| ローカル（オフライン） | Mac の外に出ない | Mac の外に出ない |

- 「外部 AI（OpenAI）で置き換え元を探す」をオンにしたときだけ、直前の音声入力の文と直した語を OpenAI に送ります。初期値はオフです。
- 「直した単語を登録する」ときの判断（普通の言葉かどうか）は、Mac の中の AI で行います。文字は外に出ません。
- API キーは、macOS のキーチェーンにだけ保存されます。
- 履歴、用語集、設定は、この Mac の次の場所に保存されます。
  - `~/Library/Application Support/VoiceInput/history.json`
  - `~/Library/Application Support/VoiceInput/glossary.json`
  - `~/Library/Application Support/VoiceInput/settings.json`
- 機密情報を話す可能性がある場合は、ローカルモードを使ってください。

## 9. 困ったとき

| 症状 | 対処 |
|---|---|
| 右 Option を押しても何も起きない | 「権限」で、アクセシビリティが許可されているかを確認してください。JIS 配列の MacBook では、設定で別のキーに変えてください。 |
| 「API キーが正しくありません」 | 設定の「API キー」に、Soniox のキーを入れ直してください。 |
| 「Soniox の残高または予算が不足しています」 | Soniox Console の Billing で、クレジットと月の予算を確認してください。 |
| 「マイクを使用できません」 | 「権限」で、マイクが許可されているかを確認してください。マイクが接続されているかも確認してください。 |
| 文字が入らず、履歴にだけ残る | 録音中に別のアプリに移ったか、パスワード入力欄でした。履歴からコピーして貼り付けてください。 |
| 「ローカルのモデルを準備中です」 | 設定の状態が「使える」になるまで待ってください。 |
| 「ローカルのモデルが使えません」 | 設定の「ローカルのモデル」に理由が出ます。「ダウンロード」でやり直すか、「削除」してからダウンロードし直してください。 |
| 直した単語の登録で「登録できる直しが見つかりませんでした」 | 直前の 10 分以内に音声入力した文を直したかを確認してください。選ぶ範囲を、直した語を含む範囲にして、もう一度試してください。 |
| 直した単語の登録で、置き換えにならずヒントだけになる | 直す前の語が普通の言葉か、2 文字以下です。Apple Intelligence が使えない Mac では、いつもヒントだけになります。置き換えにしたいときは、用語集の画面から手で足してください。 |
| 置き換えで、別の語の一部が書き換わってしまう | 置き換え元が短すぎます。用語集の画面で、その置き換えを消してください。 |

ここにない問題や、ビルド・署名・アンインストールについては、[セットアップ手順](setup.md) の「うまくいかないとき」を見てください。
