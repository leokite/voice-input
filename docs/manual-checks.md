## Task 12: 設定、用語集、履歴、権限の画面（画面を見ないと確かめられない）

- [ ] 「ぎっとはぶ」と誤認識された履歴の行で、その文字列を選んで「用語集に登録」を押し、置き換え先に GitHub を入れて登録する。次に「ぎっとはぶ」と話すと GitHub と入る
- [ ] 履歴で何も選ばずに「用語集に登録」を押すと、置き換え元に履歴の全文が入る
- [ ] 設定で「押して設定」を押し、右 Command を押す。表示が「右 Command」になり、右 Option では反応しなくなる（設定中は録音キーを押しても録音が始まらない。Esc で取り消せる）
- [ ] 文字の入れ方を録音の合間に「文の区切りごと」へ変えると、次の録音から文の区切りごとに入る
- [ ] 録音中にキーを変えても、その録音は止まらず、終わってから新しいキーが効く
- [ ] ログイン時の起動をオンにし、ログアウトしてログインすると起動している。失敗したときはトグルが戻り、赤い文字が出る
- [ ] API キーを保存すると「保存済み」が出て、キーそのものは表示されない。削除で消える
- [ ] 言語のヒントを「ja, en, ,」と入れると ja と en だけが使われる
- [ ] フィラーの追加、削除、「初期値に戻す」が効く
- [ ] 用語を大量に入れたとき、設定に警告が出る

## 最終レビューの修正（画面とマイクがないと確かめられない）

- [ ] 右 Option を押したまま、どこかをクリックする（Option+クリック）。録音が始まらず、表示も出ない。クリックは普通に効く
- [ ] 右 Option を押したまま、ドラッグする（Option+ドラッグ）。録音が始まらず、ドラッグは普通に効く
- [ ] 右 Option を押し続けて録音が始まった後、← を押す。録音が消え、何も入らず、履歴にも残らない。← は普通に効く
- [ ] ターミナルで「セキュアキーボード入力」をオンにし、右 Option を短く押す。「パスワード入力中は使えません」と出て、録音は始まらない。もう一度押しても状態が崩れない
- [ ] 話し終えて文字が入る前（処理中）にすぐ右 Option を短く押す。「処理中です」と出て、その後の押下で普通に録音できる（止まらない録音が残らない）
- [ ] メニューの「録音の開始と停止」で録音が始まり、もう一度選ぶと止まって文字が入る。メニューで始めた録音を右 Option の短押しでも止められる
- [ ] API キーが間違っている（401）とき、エラーが出て設定の画面が開く
- [ ] API キーを削除してから右 Option を短く押すと、「API キーが設定されていません」と出て設定の画面が開く。右 Option+← など普通の操作では何も出ない
- [ ] 残高不足（402）のとき、エラーが出てブラウザで https://console.soniox.com が開く
- [ ] マイクの許可を外して右 Option を短く押すと、「マイクを使用できません」と出て権限の画面が開く。右 Option+← では何も出ない
- [ ] マイクの許可が未確認（`tccutil reset Microphone dev.ykazama.VoiceInput` の後）のとき、右 Option+← では許可のダイアログが出ず、右 Option を短く押したときに出る
- [ ] リアルタイム入力で押し続けて話している間に文字が入っても、録音が消えない（自分の Cmd+V を同時押しと見なさない）
- [ ] クリップボード履歴のアプリ（Maccy、Raycast など）に、音声入力の文字が残らない
