## 最終レビューの修正（画面とマイクがないと確かめられない）

- [ ] 右 Option を押したまま、どこかをクリックする（Option+クリック）。録音が始まらず、表示も出ない。クリックは普通に効く
- [ ] 右 Option を押したまま、ドラッグする（Option+ドラッグ）。録音が始まらず、ドラッグは普通に効く
- [ ] 右 Option を押し続けて録音が始まった後、← を押す。録音が消え、何も入らず、履歴にも残らない。← は普通に効く

- [ ] メニューの「録音の開始と停止」で録音が始まり、もう一度選ぶと止まって文字が入る。メニューで始めた録音を右 Option の短押しでも止められる
- [ ] API キーが間違っている（401）とき、エラーが出て設定の画面が開く
- [ ] API キーを削除してから右 Option を短く押すと、「API キーが設定されていません」と出て設定の画面が開く。右 Option+← など普通の操作では何も出ない

## 直した単語の登録（⌃⌥D）

準備: 設定の「用語集」に「端末内AIで置き換えを判断します」と出ていることを確かめる（出ていなければ、置き換えは登録されず、ヒントだけが登録される）。

- [ ] 「Docker コンテナを再起動してから API を確認します」と話し、誤認識された部分（例:「どうか」）を Docker に直す。「Dockerコンテナを再起動」のように前後を含めて選び ⌃⌥D を押すと、「Docker を登録しました」と出る（「どうか」は普通の言葉なので、置き換えは登録されない）
- [ ] 「Kubernetes のデプロイに失敗しました」と話し、誤認識（例:「キューバーニーツ」）を Kubernetes に直して、前後を含めて選び ⌃⌥D を押すと、「キューバーニーツ → Kubernetes を登録しました」と出る
- [ ] 直した単語だけを選んで ⌃⌥D を押すと、「{単語} を登録しました」と出る（ヒントだけを登録）

- [ ] 何も直さずに選んで押すと、「登録できる直しが見つかりませんでした」と出る
